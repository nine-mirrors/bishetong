## 九、结论

主流程闭环可用：登录/注册 → 课题发布与申请 → 审核立项 → 里程碑提交与批阅 → 阶段推进 → 文档与通知 → 风险与看板。

企业管理能力已补齐：用户账号与状态管理、审计日志、CSV 导出、批量催办、全局搜索、自助改密与通知中心。

质量抽检能力已补齐：盲审抽检支持随机抽样、匿名评阅与非本人导师分配；优秀论文评选接入总评、查重率与合规分三项规则，并同步通知学生与导师。

归档可信与外部服务已补齐：归档件写入 SHA-256 摘要并支持篡改检测；阿里云 OSS 上传适配完成（未配置自动回退本地）；千问 / DeepSeek AI 辅助已接入评语、指导反馈与合规建议，未配置 Key 时安全降级。

体验层已补齐：登录页粒子光效与极光背景、全站环境粒子、AI 悬浮球 + 抽屉对话、抽屉式全局搜索；系统开启“减少动态效果”时保留背景动效，仅关闭平滑滚动。

交互层已补齐：项目专属鼠标指针仅在应用内生效，采用原生箭头造型并叠加玉青描边与琥珀点缀，支持悬停、文本、加载、左/右/中键与拖拽状态，触摸设备自动禁用。

背景与布局已复查：粒子增加闪烁、鼠标连线与环境光跟随，登录页补充浮动光球；712px / 390px 下登录表单回到首屏，全局滚动条、焦点态与状态点动画统一到 Ink & Jade 设计系统。

后端与工程质量再复查：修复日期格式化的 UTC 偏移；看板增加盲审与优秀论文质量面板；补充安全响应头、登录/AI 限流与优雅退出；移除早期 todo 示例模块与字典。

构建层已优化：Element Plus 改为 `unplugin-vue-components` 按需引入，保留 `ConfigProvider` 中文 locale 与 Message / MessageBox / Loading 样式，模块数 1747，主 JS 约 169.35KB（gzip 59.78KB），主 CSS 约 62.46KB（gzip 11.87KB），最大路由块 `ProjectDetailView` 约 155.47KB（gzip 43.59KB）。

文档与归档已增强：PDF / DOCX / MD / TXT 上传后自动解析文本与字数，解析结果可用于合规检查与全文预览；归档时自动申请 RFC 3161 可信时间戳，支持 `.tsr` 下载与摘要校验。

工程门禁（lint / test / test:unit / build / db:check）与 CI 五道 job（含 Docker 构建与容器健康检查）全部通过，无阻塞性缺陷。本轮补充了审核名额与学生立项的并发行锁、鉴权查库校验、401 统一登出与 Docker 必填密钥，并把路由 / 鉴权层断言固化为可复现的 HTTP 测试；同时补回缺失的种子文档，新增演示数据自检，避免“表有记录但文件为空”的 404。当前遗留项集中在部署验证、跨浏览器与压力测试，建议在提交前补充一轮真实环境的部署验收。
